# AI Tooling Report

## Overview

This project was developed with the assistance of AI-powered coding and research tools. AI tools were used to accelerate development, improve code quality, generate documentation drafts, and assist with troubleshooting. All generated code, documentation, and design decisions were reviewed, tested, and validated by the project author before inclusion in the final submission.

---

## AI Tools Used

### ChatGPT (OpenAI)

Primary use cases:

- Project planning and architecture design
- Retrieval-Augmented Generation (RAG) workflow design
- Flask application development assistance
- ChromaDB integration guidance
- LangChain implementation support
- Evaluation framework design
- GitHub Actions CI/CD workflow creation
- Documentation drafting and refinement

What worked well:

- Rapid generation of boilerplate code
- Assistance with debugging Python errors
- Architectural recommendations for RAG systems
- Creation of evaluation scripts and testing approaches
- Guidance for project organization and documentation

Limitations encountered:

- Some generated code required modification before execution
- Certain implementation details required manual verification
- Suggested evaluation metrics occasionally required adaptation to the project's actual data structures
- Retrieval evaluation logic required additional manual review

---

### Ollama

Primary use cases:

- Local LLM hosting
- Running the Qwen3 language model
- Generating policy-based responses without paid APIs

What worked well:

- Fully local inference
- No API costs
- Easy integration with the Python application
- Privacy-preserving workflow

Limitations encountered:

- Higher latency compared to cloud-hosted APIs
- Local resource consumption increased during evaluation runs

## Human Contributions

The following activities were performed manually by the project author:

- Creation and curation of the company policy corpus
- Selection of architecture and technology stack
- Evaluation dataset design
- Testing and validation of generated code
- Interpretation of evaluation results
- Final debugging and integration
- Preparation of project deliverables and demonstration

---

## Reflection

AI tools significantly accelerated development and documentation efforts. However, successful completion of the project still required human judgment, testing, debugging, and validation. AI-generated outputs were treated as suggestions rather than authoritative solutions.

The most effective use of AI was for rapid prototyping, troubleshooting, and documentation support. The least effective use was in evaluation design, where manual review was necessary to ensure metrics accurately reflected system performance.
